Know where data goes.

Analysis runs in the desktop app. Online enrichment and your AI configuration determine which context may leave your computer.

Local analysis
Core scans and declared dependency analysis can run locally without an AI key. This promotional website is static: it accepts no mod files, keys or analysis requests, and has no analytics or submission forms.
Online enrichment
Online enrichment is enabled by default in the desktop app and can be switched off in settings. When enabled, services may receive mod names, file hashes and platform identifiers to identify files and retrieve metadata and dependencies.
When AI is configured
Your configured AI service may receive context related to the analysis. Enrichment may automatically call that configured service. Switch off the relevant features before use if you do not want to send this context.
CurseForge integration status

CurseForge integration is planned and subject to API access approval and further implementation review. Intended uses are identifying local files, retrieving metadata and dependencies, and downloading authorised files only where permitted by the platform and after user confirmation.

Common questions

Do I need an AI key?

No. Core local scans, mod metadata reading and declared dependency analysis do not require an AI key. Once configured, AI features may send analysis context to the service you specify.

Can I download an EXE now?

The current public version, 0.5.6, is provided as source. Buttons on this page lead to the actual GitHub repository. Follow its instructions to prepare Python 3.11+ and run the project.

Does a clear check mean it will launch?

It cannot guarantee that. DAMN performs static analysis, which cannot cover every runtime interaction, configuration or environment difference. Continue with game logs and real gameplay tests.

Will my mod information be sent online?

Online enrichment in the desktop app is enabled by default and can be disabled. It sends mod names, hashes or platform identifiers as needed by the services in use. Configured AI may also receive context and be called automatically during enrichment. See “Data & API” on this page.

Can I use it commercially?

The published source uses a custom noncommercial license. Read LICENSE.txt in the repository for the scope of permission. To discuss a use outside that scope, open an issue in the project repository.

Is this an official CurseForge tool?

No. It is an independent personal project. CurseForge integration is planned and subject to API access approval and further implementation review. The platform name describes the intended integration.
